# User Stories

## Student & Accommodation Management

### Student Account & Registration

1. As a student, I want to create an account using my student information so that I can access hostel accommodation services.

2. As a student, I want to log into my account securely so that I can access my personal hostel information.

3. As a student, I want to update my personal information so that my hostel records remain accurate.

4. As a student, I want to reset my password if I forget it so that I can regain access to my account.

### Hostel & Room Search

5. As a student, I want to view available hostels so that I can choose a suitable accommodation option.

6. As a student, I want to view information about each hostel so that I can compare the available options.

7. As a student, I want to view available rooms so that I can choose a room that meets my preferences.

8. As a student, I want to see the number of occupants in each room so that I know how many people I will be sharing with.

9. As a student, I want to filter rooms by room type, price, and availability so that I can find suitable accommodation more easily.

10. As a student, I want to view hostel facilities so that I know what services and amenities are available.

### Room Booking & Allocation

11. As a student, I want to request a room so that I can secure hostel accommodation.

12. As a student, I want to select my preferred room so that I can have accommodation that suits my needs.

13. As a student, I want to receive confirmation of my room allocation so that I know where I will be staying.

14. As an accommodation officer, I want to approve or reject room requests so that rooms can be properly allocated.

15. As an accommodation officer, I want to assign students to rooms so that hostel occupancy can be properly managed.

16. As an accommodation officer, I want to transfer a student from one room to another so that room changes can be properly recorded.

17. As an accommodation officer, I want to view room occupancy so that I know which rooms are full or available.

## Billing & Payments

18. As a student, I want to view my hostel fees so that I know how much I am required to pay.

19. As a student, I want to make hostel payments online so that I can conveniently pay for my accommodation.

20. As a student, I want to receive a payment confirmation so that I have proof of payment.

21. As a student, I want to view my payment history so that I can keep track of my hostel payments.

22. As a finance officer, I want to view student payment records so that I can monitor hostel revenue.

23. As a finance officer, I want to identify outstanding payments so that unpaid fees can be followed up.

## Maintenance Management

24. As a student, I want to report a maintenance problem so that hostel staff can resolve it.

25. As a student, I want to attach a description or image of the problem so that maintenance staff can understand the issue.

26. As a student, I want to track my maintenance request so that I know whether it has been received, assigned, or resolved.

27. As maintenance staff, I want to view reported maintenance problems so that I can attend to them.

28. As maintenance staff, I want to update the status of a maintenance request so that students know the progress of their complaint.

29. As a hostel administrator, I want to view unresolved maintenance requests so that I can ensure important problems are addressed.

## Security & Visitor Management

30. As a student, I want to register an expected visitor so that the hostel security team knows who is visiting me.

31. As a security officer, I want to view registered visitors so that I can verify visitors before allowing them into the hostel.

32. As a security officer, I want to record visitor entry and exit times so that there is a record of hostel visitors.

33. As a student, I want to receive notifications about hostel security rules so that I can follow the required procedures.

34. As a hostel administrator, I want to view security records so that I can monitor hostel safety.

## Communication & Notifications

35. As a student, I want to submit a hostel complaint so that management can address problems affecting students.

36. As a student, I want to track my complaint so that I know whether it is being handled.

37. As a hostel administrator, I want to review student complaints so that I can identify and resolve recurring problems.

38. As a hostel administrator, I want to send announcements to students so that important information can be communicated quickly.

39. As a student, I want to receive hostel announcements so that I do not miss important information.

## Check-In & Check-Out

40. As a student, I want to receive check-in instructions so that I know what I need before moving into the hostel.

41. As an accommodation officer, I want to record student check-ins so that I know which students have moved into their assigned rooms.

42. As a student, I want to submit a check-out request so that my departure can be properly recorded.

43. As an accommodation officer, I want to record student check-outs so that room availability can be updated.

44. As an accommodation officer, I want to inspect a room after a student checks out so that any damages can be identified.

## Hostel Administration

45. As a hostel administrator, I want to add new hostel buildings so that the system reflects available accommodation facilities.

46. As a hostel administrator, I want to add and remove rooms so that room information remains accurate.

47. As a hostel administrator, I want to update room information so that students see current accommodation details.

48. As a hostel administrator, I want to manage student hostel records so that accommodation information remains organized.

49. As a hostel administrator, I want to view hostel occupancy statistics so that I can monitor how rooms are being used.

50. As a hostel administrator, I want to generate hostel reports so that I can make informed management decisions.

## Notifications

51. As a student, I want to receive notifications when my room application is approved or rejected so that I know its status.

52. As a student, I want to receive payment reminders so that I do not forget important hostel payments.

53. As a student, I want to receive maintenance updates so that I know when reported problems have been resolved.

54. As a hostel administrator, I want to send targeted notifications to students so that relevant information reaches the appropriate residents.

## Reports & Records

55. As a hostel administrator, I want to view the total number of students living in the hostel so that I can monitor occupancy.

56. As a hostel administrator, I want to view available and occupied rooms so that I can manage accommodation efficiently.

57. As a finance officer, I want to generate payment reports so that hostel finances can be monitored.

58. As maintenance staff, I want to generate maintenance reports so that recurring problems can be identified.

59. As a security officer, I want to view visitor records so that hostel security activities can be monitored.
